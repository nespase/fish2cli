# fish2cli

Bash-скрипт для прогноза клёва прямо в терминале.  
Реальная погода с open-meteo, анализ перепадов давления и персональные вердикты для каждой рыбы.

# Возможности:

  **16 локаций** — от Астрахани до Красноярска
  **Реальная погода** через open-meteo (никаких API-ключей!)
  **Умный анализ давления** — скрипт помнит вчерашние показания и реагирует на перепады
  **7 видов рыб** со своим характером:
    Щука, судак, окунь, сазан, лещ, карась, сом
  **Советы по приманкам и тактике** — что кидать и как вести
  **Учёт времени суток** — ночные хищники не дремлют
  **Цветной вывод** — всё красиво и понятно
  **Кэш давления** в `/tmp/` — для анализа динамики

# Зависимости
Скрипту нужны: curl, python3, bc
Ubuntu/Debian: sudo apt install curl python3 bc
Arch: sudo pacman -S curl python bc
macOS: brew install curl python bc
Windows: дорога в WSL (https://learn.microsoft.com/ru-ru/windows/wsl/install)

# Логика работы
Скрипт не просто показывает погоду — он думает как рыбак:

Рыба	                       Условия для активности
Щука	                       Падение давления или пасмурно → "Мамка охотится!"
Судак                        Высокое давление (>1014) + ночь → ждет блесны
Окунь	                       Высокое давление (>1012) + ясно → дает жару
Сазан                        Тепло (>15°C) + южный ветер → режим пылесоса
Лещ                          Стабильное давление (нет перепадов) → ждет прикормки
Карась	                     Тепло (>12°C) → активен, холодно → грустит в иле
Сом	                         Ночь → зверь, день → "спят усталые сомики"
Давление кэшируется — скрипт сравнивает с прошлым запуском и учитывает резкие скачки.
